# 心路实践团 · 沙海星火

北京科技大学心路实践团沙海星火小队赴宁夏中卫支教实践宣传页面。

## 项目结构

```
心路实践团/
├── index.html          # 主页面（单文件，CSS/JS 内联）
├── images/
│   ├── home/           # 首页封面图（3 张 webp）
│   ├── team/           # 团队成员头像（10 张 webp）
│   ├── bg/             # 背景页统计卡片底图（4 张 webp）
│   └── photo/          # 影像页照片（webp，动态加载）
└── .gitignore
```

## 页面结构

5 个横向滑动的幻灯片页面：

| 页码 | 内容 |
|------|------|
| 0 | 首页 — 左图右文 + 下翻张艳琴故事 |
| 1 | 实践背景 — 中卫关帝村介绍 + 四大主题 + 数据统计 |
| 2 | 支教日记 — 时间线（物资派发 / 教学日 / 告别） |
| 3 | 团队介绍 — 指导老师 + 队长 + 10 名队员 |
| 4 | 影像 + 联系我们 — 照片画廊 + CTA + 页脚 |

## 技术要点

- **响应式三断点**：手机 (<769px) / 平板 (769-1024px) / 桌面 (≥1025px)
- **Canvas 粒子效果**：全局悬浮 + 首页右侧局部粒子
- **首页纵向翻页**：`translateY` 切换封面与故事
- **团队卡片 hover**：遮罩 + 描述淡入，卡片尺寸不变
- **影像动态加载**：从 `images/photo/` 读取，随机网格，灯箱预览
- **Font Awesome 6**：CDN 图标库
