## 技术要点

- **响应式三断点**：手机 (<769px) / 平板 (769–1024px) / 桌面 (≥1025px)
- **首页纵向翻页**：`translateY` 切换封面与张艳琴故事
- **Canvas 粒子**：全局悬浮（橙绿双色 70 粒）+ 首页右侧局部粒子
- **团队卡片 hover**：绝对定位遮罩淡入，卡片尺寸不变
- **影像动态加载**：每次切换到影像页，从 78 张中随机抽 10 张，随机网格位置
- **日记照片自动匹配**：JS 按日期解析文件名，加载成功替换占位
- **枸杞特辑独立样式**：红色左边框 + 红底标签 + 红色圆点
- **Font Awesome 6 CDN**：图标库
- **底部结语**：`前路漫漫亦灿灿，一纸墨痕渡千山，一帧光影寄流年`
