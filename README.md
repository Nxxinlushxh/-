## 技术要点

| 项目 | 实现 |
|------|------|
| 响应式 | 手机 (<769px) / 平板 (769–1024px) / 桌面 (≥1025px) |
| 导航栏 | 三端磨砂玻璃效果（blur 40px + 35% 白底） |
| 首页翻页 | `translateY` 纵向切换封面与故事 |
| 幻灯片切换 | `scale` + `opacity` 缩放淡入淡出（0.6s） |
| 粒子效果 | 全局悬浮橙绿双色（70 粒）+ 首页右侧局部粒子 |
| 团队卡片 | hover 绝对定位遮罩淡入，卡片尺寸不变 |
| 影像画廊 | CSS Grid + 随机跨行跨列，每次切到影像页重新抽 8 张 |
| 日记照片 | CSS 背景图自动匹配，无加载失败裂图 |
| 统计卡片 | 背景图 + 渐变暗色蒙版 + 白色图标数字 |
| 首页引用 | 灰色左边框 + 深色文字，无多余底色 |
| 枸杞特辑 | 红色左边框 + 红底标签 + 红色圆点 |
| 结语 | 前路漫漫亦灿灿，一纸墨痕渡千山，一帧光影寄流年 |
| 图标 | Font Awesome 6 CDN |

## 部署

静态页面，部署到 `xinlushxh.site`（GitHub Pages + Cloudflare CDN）。

更新照片后建议在 Cloudflare 后台 Purge Cache → Custom Purge → `images/photo/*`。
